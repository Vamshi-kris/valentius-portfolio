# Vamshi — Developer Portfolio

A responsive personal portfolio built with **plain HTML, CSS, and JavaScript** for the Valentius Kryptix Fullstack Web App Development internship task.

## Features

- Semantic HTML structure (`header`, `nav`, `main`, `section`, `footer`)
- About, skills, project showcase, and contact sections
- Three project cards linking to public GitHub repositories
- Responsive layout for mobile, tablet, and desktop
- Mobile navigation menu
- Dark/light theme toggle
- Scroll-reveal effects with a reduced-motion accessibility fallback
- No framework or build step required

## Tech stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, media queries)
- Vanilla JavaScript

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in your browser, or use the VS Code **Live Server** extension.

## Before submitting

- Check the contact details and social links.
- Verify each project description matches the current repository.
- Test at 375px, 768px, and 1280px+ widths using browser DevTools.
- Open all repository links and check the browser console for errors.
- Push the final code to a **public** GitHub repository with a commit made after your internship start date.
